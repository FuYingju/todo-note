# 工作待办记事本

面向开发人员的本地化待办 / 已办 / 备忘录工具，纯前端实现，无需服务器。

## 功能

- **待办**：记录工作需求，支持备注、优先级（高/中/低）、截止日期、所属项目分组；未分组事项自动归入"默认分组"
- **已办**：完成的待办自动移入，可恢复为待办或删除
- **备忘录**：记录网址、账号密码、注意事项等非待办类重要信息（纯文本明文保存）
- **统计**：今日完成 / 今日未完成 / 今日新增、按项目统计今日完成情况、近期待办（3 天内或已逾期）、近 14 天完成趋势图

## 技术说明

- 纯原生 HTML / CSS / JavaScript（Chart.js 绘制趋势图），无构建步骤
- 数据通过浏览器 File System Access API 以 `data.json` 真实落盘到用户授权的本地目录，不上传任何数据
- 目录句柄缓存在 IndexedDB，再次打开时优先恢复并重新校验授权
- PWA 支持，可安装为桌面应用离线使用

## 部署到 GitHub Pages

1. 在 GitHub 创建仓库 `todo-note`（公开），将本目录所有文件推送到 master/main 分支
2. 仓库 Settings → Pages → Source 选择 `Deploy from a branch`，分支选 master 或 main
3. 访问地址：`https://FuYingju.github.io/todo-note/`

> 注意：GitHub Pages 上公开的只是页面代码，你的待办/备忘录数据保存在本地授权目录，不会上传。

## 首次使用

1. 使用 Chrome 或 Edge 浏览器打开页面（Firefox / Safari 不支持本地文件读写）
2. 点击"选择数据目录"，在弹窗中新建并选择文件夹，例如 `D:\work\todo-note`
3. 之后所有数据保存为该目录下的 `data.json` 文件

每次打开页面浏览器会弹一次授权确认，从弹窗的"最近使用的文件夹"选择上次目录即可。
